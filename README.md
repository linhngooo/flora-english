# Flora's Teaching Workspace 🌸

Web quản lý lớp học tiếng Anh của cô Flora: lớp & học sinh, giáo án, lịch dạy, bài tập về nhà, đánh giá kỹ năng, 11 trò chơi chiếu lớp, phim truyện đọc to, xưởng phiếu bài tập A4, thư viện, nhắn phụ huynh.

**Xem web:** https://linhngooo.github.io/flora-english/

## Sửa web
- Mở tệp `index.html` → bấm biểu tượng bút chì → sửa → **Commit changes**. Khoảng 1–2 phút sau web tự cập nhật.
- Lỡ sửa sai: vào **History** để lấy lại bản cũ.

## Lưu ý về dữ liệu
- Dữ liệu học sinh được lưu trong trình duyệt của từng máy. Người khác vào web chỉ thấy dữ liệu mẫu.
- Muốn chuyển sang máy khác: **Dữ liệu & Sao lưu → Tải bản sao lưu**, rồi **Khôi phục** ở máy mới.
- Không tải tệp sao lưu (có thông tin phụ huynh) lên GitHub.
