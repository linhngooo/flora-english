# Flora's Little English World

Website dạy tiếng Anh của cô Flora (mầm non & tiểu học: Cambridge Starters/Movers/Flyers, GrapeSEED, phonics).

**Xem web:** https://linhngooo.github.io/flora-english/

## Hai khu vực
- **Kids World** (`#kids`) – khu cho học sinh: English Reels (vuốt video ngắn), Game World (15 trò chơi), Watch & Discover, Story Time, My English Adventure (8 thế giới, sao, huy hiệu, chứng nhận).
- **Teacher Workspace** (`#dashboard`) – khu của cô: lớp học, giáo án, bài tập, đánh giá, GrapeSEED Hub, thư viện video/game (duyệt nội dung cho trẻ), tiến độ Kids World, hồ sơ giáo viên, cài đặt an toàn trẻ em, sao lưu dữ liệu.

## Dữ liệu
Trên web công khai, dữ liệu được lưu **trong trình duyệt** của từng máy (localStorage). Muốn chuyển sang máy khác: Data & Backup → tải bản sao lưu → mở trên máy mới → khôi phục.
Không đưa file sao lưu (có thông tin phụ huynh) lên GitHub.

## Sửa web
Toàn bộ web nằm trong một file `index.html`. Mã nguồn chia phần nằm trong thư mục `src/` (chạy `bash build.sh` để ghép lại).
